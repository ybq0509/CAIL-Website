# CAIL 静态网站交付包

## 使用与部署

这是可直接部署的 HTML、CSS、JavaScript 静态网站，不需要后台、数据库或构建步骤。

将本文件夹中的 HTML 文件与 `assets/` 整体上传到静态网站服务器，入口为 `index.html`。保留文件之间的相对位置。页面栏目及文件对应关系见 `PAGE-MAP.md`。

本地可直接打开 `index.html` 查看；需要通过本地 HTTP 服务预览时，在本目录运行 `python3 -m http.server 8767`，然后打开 `http://127.0.0.1:8767/`。

## 包内结构

- 根目录：正式 HTML 页面。
- `assets/`：页面实际引用的图片、标志、字体、样式与交互脚本；包含必要的字体许可文件。
- `assets/search-data.js`：由本次正式页面内容整理的全站搜索数据。
- `PAGE-MAP.md`：完整页面目录。

英文、简体中文、繁体中文共用同一组 HTML，页面中的语言属性保存对应文字。新闻和活动介绍限制为三行，详情页保留完整正文。论文图片按原比例展示，无图论文不保留空图片位。

英文正文及常规标题使用包内 Muli，学校名称使用 Futura，装饰性斜体保留衬线字体；中文采用系统黑体。

## 后续维护

更新文字时同步修改英文、简体中文、繁体中文内容；新增或删除页面时，同步修改导航和搜索数据。图片请保留相对路径引用。这里交付的是静态成品，可直接维护 HTML；用于再次生成网站的脚本和原始内容仍保留在原工作目录，不包含在部署包内。
